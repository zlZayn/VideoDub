# docs/ — 架构与设计文档目录

## 用途

存放项目的架构设计、技术决策、接口契约等深度文档。

与根目录 `README.md` 的区别：
- 根 `README.md`：用户文档，侧重用法、参数、常见问题
- `docs/`：开发者文档，侧重架构设计、数据流、模块契约、防错清单

## 文档清单

| 文件 | 内容 | 读者 |
|------|------|------|
| `ARCHITECTURE.md` | 架构设计：数据流、关键设计决策、模块接口契约、防错清单 | 开发者、维护者 |

## 文档规范

- 不使用复杂 ASCII 流程图，改为文字描述
- 仅目录树可用简单 ASCII tree
- 接口变更必须同步更新本文档
- 重大技术决策记录到 `.agents/notes/` 目录

## 阅读顺序

1. 先读根 `README.md` 了解用法
2. 再读 `docs/ARCHITECTURE.md` 理解架构
3. 然后读 `src/videodub/README.md` 了解各模块
4. 最后读 `.agents/notes/` 了解历史决策
